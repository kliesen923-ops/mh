# mh

브라우저에서 바로 즐기는 실시간 멀티플레이 2D 액션 게임입니다.
서버는 Express + Socket.IO, 계정과 전적은 PostgreSQL에 저장합니다.

## 게임 규칙

뱀파이어 서바이버식 성장 + PvP입니다.

- 맵은 3840×1920이고, 화면은 플레이어를 따라가는 카메라로 보입니다. 화면 위쪽 미니맵에 내 위치(주황), 다른 플레이어(파랑), 경험치 구슬(하늘색)이 표시됩니다.
- 플레이어마다 자기 몬스터 무리가 화면 밖에서 생겨나 자기에게만 몰려듭니다. 다른 플레이어의 몬스터도 보이고(반투명) 잡을 수 있으며, 경험치는 잡은 사람이 가져갑니다.
- 몬스터를 잡으면 그 자리에 경험치 구슬이 떨어지고, 가까이 가면 빨려 들어와 경험치가 됩니다. 구슬은 누구나 주울 수 있습니다.
- 레벨업마다 능력치 카드를 하나 고릅니다(6초). 고르는 동안 내 몬스터는 멈추고, 다른 플레이어의 공격은 처음 3초만 막아줍니다.
- 레벨이 오를수록 강한 등급이 섞여 나옵니다 (3레벨마다 한 등급).

  | 등급 | 색 | 체력 | 공격력 | 경험치 |
  |---|---|---|---|---|
  | 1 | 초록 | 16 | 3 | 1 |
  | 2 | 파랑 | 34 | 5 | 3 |
  | 3 | 보라 | 65 | 8 | 6 |
  | 4 | 주황 | 110 | 12 | 10 |
  | 5 | 빨강 | 180 | 16 | 16 |
  | 6 | 검정(금테) | 280 | 22 | 25 |

- 죽으면 그동안 모은 경험치가 주변에 구슬로 흩뿌려지고, 누구든 밟으면 주워 갈 수 있습니다. 레벨과 능력치는 1레벨로 초기화됩니다.
- 수치는 `src/config.js`의 `MOB_TIERS` 등에서 조정합니다.

## 무기와 궁극기

| 무기 | 특징 | 궁극기 |
|---|---|---|
| 한손검 | 넓은 부채꼴, 무난함 | **검기 난무**: 1.2초 동안 주변 원 안을 8번 벰 |
| 쌍검 | 공격이 가장 빠름 | **광폭화**: 4초 동안 공격속도·사거리 증가 |
| 망치 | 느리지만 한 방이 크고 몹을 밀어냄. 3타는 주변 전체를 내려찍어 몹 기절 | **대지 분쇄**: 앞쪽 큰 부채꼴에 피해 + 플레이어·몹 기절, 몹을 크게 밀어냄 |
| 창 | 길게 찌르고 일직선을 관통, 몹을 살짝 밀어냄. 3타는 더 길고 넓게 찌름 | **반사 결계**: 2.2초 동안 결계 밖 투사체를 반사하고 몹을 결계 밖으로 밀어냄 |
| 활 | 화면 끝까지 날아가는 화살 | **용의 화살**: 맵 끝까지 관통하는 큰 화살 |

궁극기를 쓰면 시전자 위에 이름이 뜨고, 실제로 맞는 범위가 바닥에 그려지며, 맞은 대상 위에 데미지 숫자가 뜹니다.

레벨업 강화는 궁극기에도 적용됩니다.
- 공격력 강화: 모든 궁극기 데미지 증가
- 사거리 강화: 궁극기 범위 증가 (무기의 처음 사거리 대비 늘어난 비율만큼)
- 공격 속도 강화: 궁극기 쿨타임 1단계당 8% 감소, 최대 40%
- 투사체 증가(활): 용의 화살이 1발씩 늘어 부채꼴로 발사

## 실행

```bash
npm install
npm start          # http://localhost:3000
```

| 환경변수 | 설명 | 기본값 |
|---|---|---|
| `PORT` | 서버 포트 | `3000` |
| `DATABASE_URL` | PostgreSQL 연결 문자열. 없으면 회원가입/로그인 API가 500을 반환하고 킬/데스는 저장되지 않습니다. | 없음 |

`accounts` 테이블은 서버 시작 시 자동으로 생성됩니다.

`localhost`로 접속하면 클라이언트가 로그인 API를 건너뛰므로 DB 없이도 바로 플레이해볼 수 있습니다.

## 테스트

```bash
npm test
```

Node 내장 테스트 러너(`node:test`)를 사용합니다. 순수 로직 단위 테스트와, 서버를 임의 포트에 띄워 Socket.IO 클라이언트로 전투·궁극기·접속 종료를 확인하는 통합 테스트가 있습니다.

## 구조

```
server.js               진입점
src/
  app.js                Express/Socket.IO 서버 생성, 시작
  config.js             게임 상수
  db.js                 PostgreSQL 연결, 계정 조회/전적 갱신
  socket.js             Socket.IO 이벤트 핸들러
  routes/auth.js        /api/auth/register, /api/auth/login
  auth/password.js      scrypt 비밀번호 해시
  utils/sanitize.js     입력값 정리
  utils/geometry.js     각도·거리 계산
  game/state.js         공유 상태 (players, io)
  game/stats.js         무기별 능력치, 사거리, 궁극기 설정
  game/action.js        클라이언트 액션 검증
  game/hits.js          공격당 중복 타격 방지
  game/combat.js        킬 처리, 활/애쉬 투사체 판정
  game/ultimates.js     무기별 궁극기
  game/pickups.js       회복 십자가, 거대화 물약
  game/mobs.js          몬스터 생성·이동·접촉 피해, 주기적 tick
  game/progression.js   경험치와 레벨업
  game/xpOrbs.js        사망 시 경험치 구슬 흩뿌리기·줍기
  game/sync.js          statsUpdate 브로드캐스트 묶어서 보내기
public/                 정적 파일 (이 폴더만 외부에 공개됩니다)
  mh.html
  style.css
  js/                   클래식 스크립트, mh.html에 적힌 순서대로 로드
    core.js             상수, 전역 상태, 플레이어
    network.js          서버 이벤트 수신
    hud.js              리더보드, HUD, 쿨다운 UI
    gameplay.js         이동·공격·스킬 로직
    input.js            키보드/마우스
    render.js           캔버스 그리기
    controls.js         모바일 조이스틱/버튼, 게임 루프
    auth-ui.js          로그인/회원가입, 무기·스킬 선택
```

클라이언트 스크립트는 전역 스코프를 공유하므로 `mh.html`의 `<script>` 순서를 바꾸지 마세요.
